# Binary to Decimal Converter

## Project Description
This project is a Binary to Decimal Converter built using digital logic gates.  
The system takes a 4-bit binary input and displays the corresponding decimal value through LEDs.

The project can display decimal values from 0 to 10.

---

## Features
- 4-bit binary input
- Decimal output using LEDs
- Built using logic gates only
- Supports outputs from 0 to 10
- Simple digital logic implementation

---

## Technologies Used
- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- XOR Gate
- LEDs
- Breadboard
- Logic ICs

## How It Works
The circuit receives a 4-bit binary number as input.  
Logic gates process the input and activate the corresponding LED output that represents the decimal value.

For example:
- Input: 0011
- Output: LED 3 turns ON
